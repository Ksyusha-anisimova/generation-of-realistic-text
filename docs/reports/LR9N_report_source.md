# Лабораторная работа №9N

**Тема:** Программное обеспечение для генерации реалистичного текста с помощью модулей искусственного интеллекта.

**Студент:** Анисимова А.А.

## Цель работы

Собрать отдельный проект с полным циклом проверки качества: unit-тесты, BDD-интеграция, CI-пайплайн из нескольких job и security-анализ.

## Что реализовано

В проекте есть сервер на Node.js и простое веб-приложение. Пользователь может:

- зарегистрироваться и войти в систему;
- выбрать модуль генерации (`creative`, `formal`, `dialog`);
- ввести запрос и получить сгенерированный текст;
- выйти из системы.

Для администратора добавлено изменение роли пользователя.

## Тестирование

### Unit

Модуль `generateRealisticText()` проверяется в `tdd/textGenerator.test.js`.
Покрыты базовые сценарии:

- корректная генерация для модулей `creative` и `formal`;
- обработка пустого запроса;
- обработка неверного названия модуля.

### BDD / Integration

Интеграционные сценарии написаны на Cucumber + Playwright.
Проверяются:

- успешный вход;
- ошибка входа с неверным паролем;
- регистрация и повторный вход;
- смена роли в админ-панели;
- генерация текста для разных модулей (Scenario Outline).

## CI/CD

В GitHub Actions настроены два workflow:

1. `CI` с jobs:
   - `test` (lint + complexity + unit coverage),
   - `integration` (BDD),
   - `report` (сбор и публикация артефактов).
2. `CodeQL` с job `analyze`.

В `report` формируется summary со списком артефактов.

## Артефакты

- `test-stage-artifacts`
- `integration-stage-artifacts`
- `ci-consolidated-artifacts`

## Скриншоты для отчета

1. Результат job `test`.
2. Результат job `integration`.
3. Результат job `report`.
4. Summary со списком артефактов.
5. Результат `CodeQL / analyze`.

## Вывод

Проект собран как отдельная лабораторная в новой директории `lab7N`. Локально проходят и базовые, и интеграционные проверки. Структура CI повторяет требуемую схему из предыдущей работы, поэтому для отчета доступны все нужные job и артефакты.
